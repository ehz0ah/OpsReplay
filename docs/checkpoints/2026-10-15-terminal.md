## Test setup

driver invoked the terminal-ticket handler with synthetic authorizer claims. It then used
the issued ticket on the real CloudFront WebSocket path. After the session ended, local
test drivers invoked the debrief, timeline, and playback handlers against the managed
DynamoDB and S3 data.

This setup exercised the deployed runtime without opening learner admission. It did not
exercise browser sign-in, API Gateway authentication, the session-start route, or the
public result-read routes.

## Limits

This checkpoint does not establish:

- browser usability or the Cognito redirect and PKCE flow;
- API Gateway authentication or routing;
- the session-start route or normal catalogue-to-session learner entry;
- public debrief, timeline, or playback reads through API Gateway;
- concurrent learner capacity or load-test results;
- a permanent hosted environment;
- final AWS cost, because billing data is delayed;
- production readiness or absence of other defects.

Run another AWS checkpoint only after a change affects a managed-service boundary or a
complete browser flow is ready for integration testing.
